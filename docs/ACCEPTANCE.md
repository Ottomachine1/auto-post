# 验收范围

## 可以验证

- 六条明确标注的演示事件，来源过滤、关键词搜索、关注、事件上下文和响应式控制台。
- 静态预览中的人工草稿与导出；连接后端后草稿持久化。
- 缺少管理令牌时业务 API 返回 401。
- 草稿保存、人工审核与审核后发布的状态门槛。
- 来源 ID 去重；真实模式不查询演示事件。
- 同草稿同渠道重复调用不会重发。
- 模拟发布返回成功 ID，人工导出不会标记为发布成功。
- 模拟结果不确定时记为 unknown，重复调用不重试。
- 演示模式在服务端禁止对外发送。

## 需要外部条件才能验收

- SSH 网络可达及目标服务器系统检查、容器启动、域名 HTTPS、部署后健康与回滚。
- RSS 目标访问权限、X API 读取配额及目标账号的用户发文授权。
- 模型兼容性、真实摘要与草稿质量。
- Telegram 目标账号权限和真实发文回执。
- Sites 源同步/打包脚本可用后才能完成其平台发布。

## 已知限制

- 当前使用 SQLite 单进程，不是高吞吐多租户生产集群。
- X 最近搜索每轮 10 条，RSS 每源 40 条，不保证突发期间完整捕获；没有 X filtered stream、分页游标、指数退避或数据回补。
- 浏览器采用每 5 秒轮询（服务器另有 SSE），来源默认每 60 秒轮询；不承诺亚秒级全球事件覆盖。
- 未实现跨来源语义去重、自动事实核验、交易所实时行情或行情推送。
- Truth 采集未接入，币安/OKX/Truth 发文仅人工导出。
- API Token 刷新、多人账号权限、定时发文、媒体附件、草稿修改与投递重试运维界面未实现。
- 未接入的状态显示“待配置”；实际 API 调用成功才可验收，不把存在环境变量视为连接成功。

## 本地验证记录

8 项 pytest 通过；JavaScript 语法检查通过；桌面/手机浏览器验证创作、审核、演示外发拦截、搜索和关注，未发现页面 JavaScript 错误或手机横向溢出。Docker 镜像构建及容器健康、认证、静态页面、草稿写入与容器重启后持久化验证通过。此验证发生在构建环境，不代表已部署目标服务器。
