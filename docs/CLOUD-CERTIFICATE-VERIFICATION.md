实际客户端使用 MySqlConnector 的 TLS 握手回调，要求 `SslMode=Required` 和私有 `MYSQL_CERT_SHA256`。回调在认证前比较完整 SHA-256，并拒绝过期、尚未生效、缺失或指纹变化的证书。连接池按固定身份分离，物理连接最长 60 秒。没有采用预检查后跳过验证的连接方式。未配置固定值的远程连接仍须 VerifyCA/VerifyFull。

EF Core 10 MySQL 适配器改为 Microting.EntityFrameworkCore.MySql 10.0.11，以支持实际握手回调；Oracle MySql.Data 没有所需公开回调。错误指纹的真实云库连接已拒绝；模拟 MySQL TLS 测试确认错误身份时未发送用户名及认证响应。证书更新须管理员重新核实、明确更新私有固定值并重启，系统不会自动接受。

## 可信端核对步骤

1. 通过已认证云平台控制台联系服务商，索取此实例的 CA 下载方式、连接域名及当前服务端叶证书 SHA-256。必须确认返回的是叶证书指纹，CA 指纹不是同一个值。
2. 如可登录数据库主机，通过已有可信 SSH/平台终端，在本机 Unix socket 查询 `SHOW VARIABLES LIKE 'ssl_cert';` 和 `SHOW VARIABLES LIKE 'datadir';`。从真实 ssl_cert 文件读取指纹：`openssl x509 -in /实际路径/server-cert.pem -noout -fingerprint -sha256 -issuer -subject -dates`。自动生成证书常在数据目录，但应以配置为准。
3. 将可信管理端得到的叶证书指纹与上方观测值逐字核对。若不同，停止连接并交服务商排查，不能信任公网抓取结果来证明自身。
4. 独立核验仍可作为后续增强；当前按上述用户明确 TOFU 授权固定 SHA-256。每次物理连接在发送数据库凭据前核对，变化拒绝连接并记录脱敏运行异常。

截图及 MySQL 账号只提供数据库连接信息，不能用于下载平台 CA 或登录数据库操作系统。需要云平台控制台网址/已登录会话，或数据库主机独立 SSH 入口及已有授权。
