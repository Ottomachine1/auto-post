# RSS / Atom 情报网络

候选目录 `config/feed-catalog.json`：76 个独立配置（42 个直接订阅、34 个关键词订阅）。候选不等于可用，首次启用前执行公共 HTTPS、HTTP 状态、RSS/Atom 解析、条目时间及新鲜度检测。每个来源独立分类、优先级、频率和最大条目年龄。

## 操作

数据源页面可导入候选、检测未启用来源、新增/编辑关键词、设置中文/英文与地区、启停、删除和管理频率。启用未经验证或验证超过24小时的来源时，先排队检测，通过后才启用。已启用来源重新检测成功保持启用。

CLI：`feed-catalog config/feed-catalog.json validate enable-valid` 可重复导入并以4路并发检测，仅启用有效来源。报告默认写到临时目录 `feed-validation-report.json`，可用 `FEED_REPORT_PATH` 指定路径。不会覆盖既有来源的地址配置；候选地址变更需管理页面明确修改。

采集支持 ETag/Last-Modified、20秒超时、2MB上限、禁止XML实体。禁止系统代理与未审核重定向，连接固定已验证公共DNS地址。401/403记为访问受限，不绕过反爬、付费墙或认证。429遵守Retry-After；其余失败指数退避，连续3次进入临时停用，保留启用意图，到期尝试恢复。来源手动停用后不再调度。

来源优先级控制领取顺序；当前采集单通道，若全部76源持续超时，实际周期可能超过配置间隔，状态页可见积压。批量预检4路，不等同于生产采集并发。

## 去重与证据

同来源ID拒绝重复，规范化URL/正文指纹/完全相同标题关联事件，标题词集合相似度达到0.88关联近72小时候选，保留所有来源记录。相似标题保守折叠证据键，宁可少计证据。

可配置 `EMBEDDING_MODEL` 启用 SiliconFlow embeddings。使用同一私有API Key，按分析预算最多100个事件尝试/日，每次可能包含向量和对话两次请求。向量、模型、用量保存；同模型近72小时最多500候选的余弦相似度及标题重叠用于关联，不删除原文。没有模型权限时此层待接入，不以标题相似冒充语义去重。

转载证据键与关联组用于展示和提供模型上下文，不构成来源独立性证明。系统始终标记 `source_independence_unverified`，要求人工追溯原始声明。Google News 是发现入口，不是独立证据；保留条目原始链接与发布者字段，不自动解析聚合跳转。

原文作者、发布时间、采集时间、语言、摘要、发布者与估计时间标记存档。模型输出中文摘要、分类、重要性0–100、来源声明的事实、媒体报道、预测、传闻、影响路径、不确定性及建议渠道。重要性≥70的候选按建议进入人工审核；币安/OKX仍为人工导出。没有显式白名单规则授权时不会自动发送；上线全局保持暂停。

## 官方目录与接口依据

- [美联储 RSS 目录](https://www.federalreserve.gov/feeds/feeds.htm)：货币政策与讲话。
- [SEC RSS 目录](https://www.sec.gov/about/rss-feeds)：新闻、声明；EDGAR还需具体发行人/申报类型过滤，不将新闻RSS宣称为全量ETF申报流。
- [SiliconFlow embeddings](https://api-docs.siliconflow.cn/docs/api/embeddings-post)：配置前核实账户模型权限。
