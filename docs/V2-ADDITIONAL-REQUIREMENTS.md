用户要求继续完整实施 V2，并在计划目标后完善 X 发文选项（参考提供的普通推文截图），扩充中文及英文全球 RSS，为网站来源自适应评分，为每条情报显示 0–100 重要性分数。

X 编辑器继续保留文字、链接、拖拽图片及预览；新增选项必须对应实际平台权限和可用接口。受众、回复权限、GIF、投票、定时、位置等逐项核对平台支持后实施，不用只有图标而不能提交的控件冒充功能。缺权限的选项清晰标示。

来源扩充沿用预检、独立调度、ETag/Last-Modified、访问限制检测和退避。中文及英文覆盖全球、宏观、政策、科技和加密；未经验证的候选源不能直接启用。

来源权重与事件重要性分开保存，包含版本、证据、更新时间与人工覆盖记录。来源评分综合官方身份、历史成功率、及时性、独立交叉验证及经核实的流量数据；没有可信流量数据时标记未知，不虚构排名，不将流量等同真实性。基于真实采样动态更新，保留样本量与置信限制，转载不重复算独立证据。

事件重要性显示 0–100 与评分理由，复用 V2 五维权重及模型预算、缓存、版本和人工反馈。模型分析是辅助信号，不将未验证报道升级为事实；未分析事件可给规则评分并明确标示，不能用随机分数或伪装模型结论填满页面。

交付顺序继续按 V2：手动翻译、发布生命周期、主题，随后统计/过滤/评分与 Agent，最后追加发文选项完善及来源扩展验收。新增评分需覆盖来源未知、样本不足、转载、过时事件、模型失败及人工纠偏。
